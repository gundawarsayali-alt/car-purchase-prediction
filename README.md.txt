   # Car Purchase Amount Prediction

   Predicts a customer's car purchase amount using regression models
   (Linear, Ridge, Lasso, Decision Tree, Random Forest) with a Streamlit web app.

   ## Files
   - `notebooks/` - EDA, preprocessing, model training and comparison
   - `app.py` - Streamlit app
   - `best_model.pkl` - saved best model
   - `carpurchasing.csv` - dataset

   ## Run locally
   pip install -r requirements.txt
   streamlit run app.py
